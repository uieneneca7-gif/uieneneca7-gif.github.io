# Portfólio — Uie Nene Cá

Portfólio pessoal de **Uie Nene Cá**, estudante de Análise e Desenvolvimento de Sistemas (Estácio), com foco em suporte técnico, redes e cibersegurança.

🔗 **Site:** https://uieneneca7-gif.github.io
📄 **Currículo:** https://uieneneca7-gif.github.io/curriculo.html

## Tecnologias

- HTML, CSS e JavaScript puro (sem frameworks)
- [Supabase](https://supabase.com) (PostgreSQL) como banco de dados
- Hospedagem no GitHub Pages

## Funcionalidades

- Tema claro/escuro salvo no navegador
- Animações ao rolar, efeito de digitação e cards com efeito 3D
- Projetos carregados do banco de dados, com filtro por categoria
- Formulário de contato com validação, que salva as mensagens no banco
- Painel administrativo com login para ler mensagens e gerenciar projetos
- Segurança com Row Level Security (RLS): visitantes só leem projetos publicados e só enviam mensagens
- Layout responsivo (celular e computador)
